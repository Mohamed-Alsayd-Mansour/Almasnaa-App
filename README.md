# تطبيق المصنع (Almasnaa)

تطبيق Flutter لإدارة ومتابعة إنتاج الغرف داخل المصنع عبر ثلاث مراحل مترابطة:
**الغرف ← اليومية ← السجل ومتابعة النواقص**.

## طريقة التشغيل

```bash
flutter pub get
flutter run
```

يتطلب Flutter SDK (نسخة مستقرة حديثة، 3.19 فأعلى) مثبتًا على جهازك.
يعمل التطبيق على Android وiOS وDesktop **وWeb** بدون أي إعداد إضافي،
لأن التخزين المحلي يعتمد على `shared_preferences` (وهو حزمة Dart
خالصة تُترجَم تلقائيًا إلى `localStorage` في المتصفح)، بدلًا من
مكوّنات أصلية (native plugins) مثل sqflite التي لا تعمل على الويب.

## هيكل المشروع

```
lib/
  core/          الثيم والألوان والمقاييس الموحّدة
  models/        Room, DailySession, DailyEntry + Enums
  database/      طبقة التخزين الخام متعددة المنصات (AppDatabase)
  repositories/  طبقة الوصول للبيانات (Repository Pattern)
  providers/     إدارة الحالة (ChangeNotifier + Provider)
  utils/         حساب النواقص، تنسيق التاريخ/الوقت
  widgets/       عناصر مشتركة (شارة الحالة، خلية النواقص، ...)
  screens/       شاشات التبويبات الثلاثة والنماذج (Forms)
```

## القواعد الجوهرية المطبّقة

- **Snapshot عند التسجيل**: عدد القطع يُنسخ داخل `DailyEntry` وقت الإضافة،
  فلا يتأثر أي سجل قديم بتعديل بيانات الغرفة لاحقًا.
- **تكرار الغرف مسموح**: يمكن إضافة نفس الغرفة عدة مرات في نفس اليومية،
  فكل إدخال وحدة إنتاج مستقلة له معرف خاص.
- **حساب النواقص تلقائيًا**: نص فارغ = 0، وإلا فعدد `-` + 1
  (`lib/utils/deficiency_calculator.dart`).
- **أصلي مقابل حالي**: نحتفظ بـ `originalDeficiencies` كما سُجّلت وقت
  الإنتاج، و`currentDeficiencies` القابلة للتعديل من تبويب السجل، مع
  تسجيل وقت آخر تعديل.
- **ألوان الحالة**: أخضر شفاف للمكتملة، أحمر شفاف للتي بها نواقص،
  مشتقة دائمًا من نص النواقص الحالي وليست قيمة مخزّنة منفصلة.
- **إغلاق اليومية لا يحذف شيئًا**: تتحول اليومية إلى `closed` وتبقى
  جميع إدخالاتها مقروءة من تبويب السجل.

## جاهزية للتوسع المستقبلي

طبقة `DailyEntryRepository.getQuickStats()` توفر أساسًا جاهزًا لبناء
لوحة إحصاءات (Dashboard) لاحقًا دون تعديل هيكل قاعدة البيانات، كما
يسهل استبدال SQLite بمصدر بيانات آخر (مزامنة سحابية مثلًا) لأن كل
منطق الوصول للبيانات معزول داخل `repositories/` فقط.
